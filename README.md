# 🛒 Comparador de Precios - Fontibón

Comparador de precios de supermercados en Fontibón, Colombia.
Rastrea automáticamente productos en Olímpica, Éxito, Carulla, Jumbo, Metro, Alkosto, Makro, Surtimax y D1.

## ✨ Features

- 🔍 Búsqueda por nombre de producto
- 📊 Comparación automática entre supermercados
- 💰 Cálculo de ahorro (diferencia entre el más caro y el más barato)
- 🗂️ Filtros por categoría
- 🔄 Actualización automática diaria (3:00 AM)
- 🕵️ Auto-descubrimiento de productos nuevos
- 📱 Diseño responsive (vista en tarjetas)

## 🛠️ Stack

- **Python 3.11**
- **Flask** (servidor web)
- **Playwright** (scraping con navegador real)
- **SQLite** (base de datos local)
- **Schedule** (job programado)
